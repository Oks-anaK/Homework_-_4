# Проект Product categories

## Описание:

Проект Product categories - приложение для анализа товаров. Приложение будет подсчитывать количество категории товаров и количество 
products в целом.

## Установка:

1. Клонируйте репозиторий:
```
git clone https://github.com/Oks-anaK/Homework_-_4
```
2. Установите зависимости:
```
pip install -r requirements.txt
```
## Использование:

В модуле [product_categories.py](src/product_categories.py) реализованы классы Product и Category, которые:
1. Позволяют получать имя, описание, цену и количество товара. 
2. Выдают категорию, описание категории, список товаров в категории. 
3. Подсчитывают количество категорий и товаров в целом.

## Тестирование:

Проект покрыт тестами с использованием фреймворка pytest.
