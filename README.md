# Проект Product categories

## Описание:

Проект Product categories - приложение для анализа товаров. Приложение будет подсчитывать количество категории товаров и количество 
products в целом.

## Установка:

1. Клонируйте репозиторий:
```
git clone https://github.com/Oks-anaK/Homework_-_4
```
2. Установите зависимости:
```
pip install -r requirements.txt
```
## Использование:

В модуле [product_categories.py](src/product_categories.py) реализованы классы Product и Category, которые:
1. Позволяют получать имя, описание, цену и количество товара. 
2. Выдают категорию, описание категории, список товаров в категории. 
3. Подсчитывают количество категорий и товаров в целом.
4. Позволяют изменить цену товара. Если новое значение цены не положительное, то новое значение приватному атрибуту цены 
не присваивается и выводится сообщение «Цена не должна быть нулевая или отрицательная» в консоль.
5. Добавить новый товар в приватный список продуктов.
6. Получить строку со всеми продуктами из приватного списка продуктов в формате: "Название продукта, X руб. Остаток: X шт.\n".
7. Метод new_product() принимает на вход два аргумента — cls и продукт для создания в виде словаря — и возвращает 
экземпляр класса Product на основе данных словаря.
8. Позволяет получить значение приватного атрибута цены.
9. Для удобства работы с продуктами реализована возможность их складывать.
10. Добавлены строковые отображения "Название продукта, 80 руб. Остаток: 15 шт.", "Название категории, количество 
продуктов: 200 шт." в класс Product и Category соответственно.

В модуле [product_iterator.py](src/product_iterator.py) реализован итератор, который:
1. Можно перебирать товары одной категории.

В модуле [smartphone_lawngrass.py](src/smartphone_lawngrass.py) созданы 2 класса - Smartphone и LawnGrass, которые 
являются подклассами Product и:
1. Содержат дополнительные атрибуты, характерные для категории.
2. Имеют непересекающиеся методы сложения продуктов категории.

В модуле [baseproduct.py](src/base_product.py) реализован базовый класс для класса продуктов.

В модуле [print_mixin.py](src/print_mixin.py) создан класс-миксин, который будет при создании объекта, то есть 
при работе метода __init__, печатать в консоль информацию о том, от какого класса и с какими параметрами был создан объект.

В модуле [exceptions.py](src/exceptions.py) реализован класс исключений, который отвечает за обработку событий, когда 
в «Категорию» добавляется товар с нулевым количеством.
